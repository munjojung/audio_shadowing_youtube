콘텐츠 선택

콘텐츠를 선택하면 게시 버전의 JSON을 자동으로 불러옵니다. 이전 버전은 목록에서 선택하세요. 저장 시 기존 버전을 덮어쓰지 않고 새 버전을 만듭니다.

콘텐츠를 변경하면 이전 JSON 편집 내용이 지워집니다. 필요한 내용은 먼저 별도로 저장하세요.

.json 파일을 이 입력창에 끌어 놓을 수 있습니다. 파일을 읽은 뒤 JSON 검증 결과를 표시합니다.

미리보기는 현재 편집창의 JSON을 사용하며 학습 점수를 서버에 저장하지 않습니다. Draft도 미리 볼 수 있습니다.
